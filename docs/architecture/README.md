Kept:      2026-11-06, on the trunk (fix/normalization-and-discovery). A release's copy describes that
           release; where the trunk is ahead of main a diagram says so in its header.

           behaviour; each diagram names the files it draws and the proofs that hold them.
Rendering: every diagram is Mermaid in a fenced block, which GitHub renders in place.
